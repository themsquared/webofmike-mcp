Live index of webofmike.com. Two read-only tools: search_posts and get_post.

Streamable HTTP endpoint

https://mcp.webofmike.com/mcp

Fallback while DNS propagates: https://webofmike-mcp.netlify.app/mcp. Point Cursor, Claude, Hermes, Gemini, or MCP Inspector at this URL. POST JSON-RPC; no credentials.

  • search_posts — query → title, slug, URL, summary, date
  • get_post — slug → markdown body, canonical URL, title, date, tags/series
